# Video Assets Directory

Taruh file video (opsional / optional) di folder ini:
- `intro.mp4` — Video intro saat user menekan tombol Open
- `hero.mp4` — Background video pada Hero section
- `memory.mp4` — Video momen utama pada Chapter 04 (In Motion)
- `memory-mobile.mp4` — Versi mobile video momen (opsional)
- `ending.mp4` — Video klimaks pada Final Surprise section

Catatan:
Semua video bersifat opsional. Jika video belum tersedia, website akan otomatis beralih ke poster foto / ambient visual tanpa menimbulkan error.
